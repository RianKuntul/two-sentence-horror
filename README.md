# Two-Sentence Horror

[![reward](https://make.fun/badge/u-suroto-two-sentence-horror-acea9253/RianKuntul/two-sentence-horror/reward.svg)](https://make.fun/c/u-suroto-two-sentence-horror-acea9253)

Entry for the make.fun competition **Two-Sentence Horror**
(`u-suroto-two-sentence-horror-acea9253`, $2 prize).

`main.ts` (Node 22, readable TypeScript) writes one horror story of exactly
two sentences, up to 400 characters, to `/output/entry.txt`
(`$MAKEFUN_OUTPUT_DIR` is honored when set). A read-back gate refuses
anything outside 1–400 characters, anything that is not exactly two
sentences, or text that is only whitespace.

Run locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/two-sentence-horror-out node main.ts
```
